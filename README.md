# Salary Management System

## Project Overview
An object-oriented Java application that manages employee records and automates salary/tax calculations using a polymorphic engine.

## Key Features
* **Polymorphic Salary Engine**: Supports different employee types (Full-time, Contractor) with specialized tax logic.
* **Robust Validation**: Custom exceptions (`InvalidEmployeeDataException`) to ensure data integrity.
* **Data Persistence**: Integrated MariaDB for efficient record management and reporting.

## Tech Stack
* **Language**: Java
* **Database**: MariaDB
* **Concepts**: OOP (Inheritance, Polymorphism), Exception Handling

## How to Run
1. Setup MariaDB database.
2. Update the MariaDB Connector/J path in your IDE.
3. Execute the main driver class to start the management console.
